V6 Patch 升级路径

选择当前正在运行的 Patch 版本和目标升级版本，系统会根据版本差异自动生成镜像清单、拉取镜像并打包。

适用场景： 已知当前版本与目标版本，且希望由系统自动计算中间差异。目标版本下拉框只会展示高于当前版本的可升级版本。

V7 镜像清单输入

手工填写镜像名称和标签，适合 V7 或临时镜像组合场景。每行一条，或使用逗号分隔，提交后将直接写入任务专属 patchlist。

推荐格式： deepflow-agent_tag: v6.6.5617 deepflow-server_tag: v6.6.5617

使用说明与操作建议
1. 先看右侧已有升级包

右侧资源区会展示服务器中已经存在的升级包。若所需版本已经生成，直接下载即可，不必重新拉取镜像和打包。

2. V6 模式怎么用
  • 选择当前 Patch 版本。
  • 选择目标 Patch 版本。
  • 点击“开始构建”，系统会自动生成差异镜像清单并打包。
  • 适合标准补丁升级路径。
3. V7 模式怎么用
  • 在镜像清单输入框中填写镜像和标签。
  • 支持每行一条，也支持逗号分隔。
  • 建议使用 name_tag: vX.Y.Z 或 name: vX.Y.Z 形式。
  • 适合自定义镜像集或非标准升级路径。
deepflow-agent_tag: v6.6.5617 deepflow-server_tag: v6.6.5617
4. 构建过程中看哪里
  • 左侧任务面板会显示进度、状态和实时日志。
  • 任务完成后，下载按钮会出现在状态面板中。
  • 构建完成后，右侧已有升级包列表也会自动刷新。
5. 下载与过期说明
  • 当前任务完成后，会先给出临时下载入口。
  • 若临时入口过期，可到右侧“已有升级包”区域再次下载。
  • 若下载失败，先刷新已有升级包列表确认文件是否已存在。
6. 常见建议
  • V6 适合规范升级，优先用 V6。
  • V7 输入镜像时，尽量一行一条，便于排查格式问题。
  • 构建失败时先看日志区最后几条错误信息，再决定是否重试。
